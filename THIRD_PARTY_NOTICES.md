# Third-party notices

This repository's MIT license applies only to the original build and release automation. ImmortalWrt and every package in the generated firmware retain their own licenses.

The firmware is built from the official ImmortalWrt 25.12.1 `x86/generic` ImageBuilder without custom packages or file overlays. Each Release includes the exact package manifest, commit-pinned source inventory, upstream provenance records, and an SPDX 2.3 package SBOM.

Primary upstream source: <https://github.com/immortalwrt/immortalwrt>

The package metadata registry records narrowly scoped license and source overrides needed to produce a complete SBOM when official binary metadata is incomplete. It does not cause additional packages to be installed.
